# ✝️ Fia and the Jealous Paladin

Image and Sound FX for the [Fia and the Jealous Paladin scenario](https://play.aidungeon.com/scenario/0J_93AyciEbE/fia-and-the-jealous-paladin?share=true&published=true) available on AI Dungeon, using the extension "AI Dungeon Extension v2 Resurrected", originally created by LeClaudia and currently mainted by mahesvara.1337 (on [AI Dungeon Discord server](https://discord.gg/K8eEW8zRy2).)

### What Does Repo Includes?
This repo features individual portraits, icons, authentic music and sound FX. Each of the major characters have 4 portraits accompanied with 4 icons suiting to each portrait.

**Portraits** are tuned to add immersion, and you can select the suiting portrait according to the ongoing narrative. (Primarily oriented around relaxed, combat, intimate and sad themes.)

**Location Pictures** are primarily prepared to use with the *Focus* feature of the Dungeon Extension V2 Resurrected.

**Sound FX and Musics** are selected from across the anime & game soundtracks across the anime and gaming community. Most entries (portrait, location, item, event) are accompanied with the suiting sound FX or music when applicable.


### How to Install & Use Dungeon Extension V2 Resurrected?
-Go to [Chrome Extension Store](https://chromewebstore.google.com/detail/keegfhpckdjecndjlgmjnjlfhlnepiga?utm_source=item-share-cb) or [Mozilla Firefox Extension Store](https://addons.mozilla.org/en-US/firefox/addon/dungeonextensionv2resurrect/) and enable it in AI Dungeon.
-Start a gameplay on the [Fia and the Jealous Paladin scenario](https://play.aidungeon.com/scenario/0J_93AyciEbE/fia-and-the-jealous-paladin?share=true&published=true) and click to the AI Dungeon Logo on the upper left corner of the gameplay page, then select **Editor** in the menu.
-Navigate to the **Settings** page from the top selection, go to the **Github Repos** drop-down menu.
-Copy **this Repository's** address from the top search bar, and paste it to the bar in the **Githup Repos menu in Dungeon Extension** menu and click **Add**.
-Navigate back to the **Adventure** menu from the top, open the **Adventure Picker** dropdown menu.
-Click **Import Adventure** and select **From GitHub**.
-Select *AIDungeon---Fia-and-the-Jealous-Paladin* from the menu.
-Import the adventure files.
-Dungeon Extension will automatically select the last file you imported as for the current adventure, and you should see all the info on the Editor screen.
-Close the editor, and have fun!
